# D-DBA-17: Support bundle redaction fails closed and works by shape
**Status:** Accepted
**Date:** 2026-11-13
**Issue:** DBA-17
**Confluence:** none (design in epic DBA-1)

**Decision:** `tools.redact.redact` replaces anything that could be an identifier, at the cost of hiding harmless text. Every absolute file path becomes `<path>` whole, chosen by the shape of the text (a root such as `/`, `~/`, `C:\`, `\\server` or the home folder, then at least one component) and never by which error message carries it; paths under the home are `<path>` too, not `<home>/...`. `Wallet_<NAME>` names database `<NAME>` wherever it appears. A dotted quad is an address unless version context in the text says otherwise (`Release`, `Build` or `version` before it, or a fifth dotted group). Every JSON string is redacted before encoding, never the encoded text. Names a text carries (hosts, services, SIDs, TNS aliases and users from connect errors, wallet database names) are added to `Known` by `redact` itself as well as by `collect`, so a caller that forgot to collect still gets them redacted.

**Why:** The pack is meant for production databases, and every leak in the first attempt (PR #19, closed unmerged) came from a real bundle built against a test container with broken saved connections. That attempt redacted local paths one Oracle message at a time (ORA-12154, then ORA-12263); each review round found another message naming an Autonomous Database wallet folder, which publishes the database name (ORA-17956 for a moved TCPS wallet; by inspection sqlnet.ora `WALLET_LOCATION` errors and cloud config zip paths). Wallet folders usually live under the home, so keeping `<home>/...` readable would have left the leak open. Encoding first doubles Windows backslashes and breaks the home and path patterns.

**Rejected:** Redacting paths per Oracle message: every review round found another wallet-naming message. Keeping folders under the home readable: wallet folders live there. Exempting values such as doctor's bare SQLcl version (`26.1.0.0`, shown as `<ip>`): each exemption keyed to a value is a way for a real address to survive; `versions.json` keeps the full SQLcl and Java lines instead. Matching `Wallet_` in any case: sqlnet.ora's `WALLET_LOCATION` would turn `LOCATION` into a database name. The first attempt's draft of this record lived only on the closed branch and rejected generic path redaction; it never merged, so nothing is superseded.

**Impact:** A new exception in `redact` must be tied to context in the text, never to the value alone, and must not be keyed to one error message. New text written into the bundle goes through `redact` string by string before any encoding. Accepted residual risk, stated in the bundle's `README.txt`: a relative path that names an identifier and is not a `Wallet_*` name is not redacted. A folder may hold spaces when a `\` or `/` follows it, whatever the root; the last component of a path still ends at its first space, because it cannot be told apart from the prose after it, so `/opt/Oracle Wallet` reads `<path> Wallet`.
